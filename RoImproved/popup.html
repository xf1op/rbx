Banned Profile Thumbnails

Configure generated thumbnails

Regular accounts use Roblox's public headshot service. For banned or deleted accounts that return blocked thumbnails, Open Cloud generation needs a key. In Creator Dashboard, create a key with the Thumbnails API and enable Generate User Thumbnail and Get User Thumbnail Generation Operation. The key is sent only to apis.roblox.com. Without a key, RoImproved still tries public headshot/bust thumbnails and an avatar-render fallback where Roblox permits it. A removed account may not have an accessible avatar definition. Never share the key or put it in scripts or public repositories.
